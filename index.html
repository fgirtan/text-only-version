Vezi ce conține HTML-ul livrat de server, înainte de execuția JavaScript — în stilul vechiului Google Cache „Text-only version”. Util pentru a verifica dacă un site JS (React, Next.js, Nuxt, Angular…) este pre-randat pe server.

🔬 Compară cu DOM-ul randat (testul decisiv)
  1. Automat: bifează „Randează și cu JavaScript” de sus — serverul încarcă pagina în Chromium și completează câmpul de mai jos.
  2. Cel mai fidel față de Google: Google Search Console → URL Inspection → Test live URL → View tested page → tab HTML → copiază tot.
  3. Alternativ: deschide pagina în Chrome → DevTools (F12) → Elements → click dreapta pe <html> → Copy → Copy outerHTML.
  4. Lipește mai jos și apasă „Compară”. HTML-ul brut de sus este comparat cu cel randat după JavaScript.
